## 📌 Notes

- Each folder contains the source code (`.py` and/or `.ipynb`) for the respective project.
- Large datasets and model weight files have been excluded from version control to keep the repository lightweight. Where applicable, dataset sources are referenced within each project's own README or notebook.
- This repository was compiled for submission as a single, consolidated public repository containing all selected assignments.
